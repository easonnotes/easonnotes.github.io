# How to publish a note

You write. Everything else is handled for you.

---

## The three steps

**1 · Write it in whichever language comes naturally.** English or Chinese, doesn't matter. Write it the way you'd say it. Don't clean it up.

**2 · Send the text.** You'll get back three files, already named and formatted:

```
_posts/YYYY-MM-DD-slug-en.md
_posts/YYYY-MM-DD-slug-zh.md
_posts/YYYY-MM-DD-slug-fr.md
```

**3 · Upload them.** On GitHub: **Add file → Upload files → drag all three in → Commit changes.** Live in about two minutes.

That's it. No editing, no config, no renaming.

---

## What every note needs

Four things. The first three are the core — they go at the top of the page, in a box.

| | |
|---|---|
| **Judgment** | What you concluded. One sentence. |
| **Counter** | The strongest argument against yourself. Not a weak one you can knock down. |
| **Falsifier** | What would show you were wrong. Must be checkable later. |
| **The note itself** | Everything else — what happened, what you were thinking, what you'd do differently. |

If you can't write the Counter, the note isn't finished. That's the hardest line and it's the reason the whole thing works.

---

## Rules that don't move

- **Closed positions only.** Nothing about a trade you're still in.
- **Only realised numbers.** Money you didn't make is not a loss. Don't put it in the ledger.
- **Say which it was: didn't know, or knew and didn't do it.** Those are different problems with different fixes. Name it every time.
- **Rules need an expiry test.** When you add a rule, say what would make you drop it. A rule you can't test becomes superstition.

---

## Every month

Look back at the month's notes and answer one question:

> **Which rules did I actually use this month?**

Rules that never got used either get deleted or get a note explaining what they're waiting for. This stops the rulebook from growing until it contradicts itself.

---

## About the translations

The English and Chinese are close to what you wrote. The French is machine-translated, and every French page says so at the bottom, with a line pointing back to the original. Nobody is misled, and you don't have to check a language you don't read.

The site remembers which language you wrote in. That matters — three years from now, you'll want to know which version was actually yours.
